ESTRUCTURA PARA GITHUB PAGES
----------------------------
Sube TODO el contenido de esta carpeta a la RAIZ del repositorio.
El archivo index.html debe quedar directamente en la raiz del repositorio.

Correcto:
  /index.html
  /style.css
  /app.js
  /apriltag.js
  /apriltag_wasm.js
  /apriltag_wasm.wasm
  /assets/logo-roboteca.png
  /assets/softrobot.png
  /assets/huincha-logos.png

No debes dejar una carpeta intermedia tipo:
  /apriltag-web-main/index.html

Luego activa GitHub Pages desde Settings > Pages y selecciona el branch/carpeta donde esta index.html.

IMPORTANTE
----------
Los nombres de las imagenes fueron cambiados para evitar espacios y problemas de mayusculas/minusculas
entre Windows y los servidores Linux de GitHub Pages.
